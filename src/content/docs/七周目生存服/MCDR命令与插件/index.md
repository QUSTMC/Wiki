## MCDReforged
MCDReforged是一个管理 Minecraft 服务器的工具，拥有自定义插件系统。完全无需修改 Minecraft 服务器本身

[MCDR基础命令](./0_mcdr命令)

## MCDR插件

### [Gamemode 旁观 / 生存切换](./1_gamemode)

旁观者模式以旁观，返回生存时传送回原坐标

### [Task 工程任务展示](./2_task)

用于展示进行中的工程任务的插件

### [Where2go 坐标点共享与位置查询](./3_where2go)

一个功能强大的位置插件，包含共享坐标点、查询玩家位置等功能

### [Prime Backup 备份与回档](./4_primebackup)

一个强大的MCDR备份插件，一套先进的Minecraft存档备份解决方案

### [Scheduled Restart 定时重启](./5_scheduled_restart)

按 Linux cron 表达式定时重启服务器，支持多条自定义提醒（聊天框 / 大标题）

### GUGU WebUI 网页管理面板

通过webui来管理所有插件、模组、配置、在线插件库、终端、玩家和服务器管理等多种功能

### Minecraft Data API 玩家数据接口

一个用获得玩家信息等数据的的 API

### OnlinePlayerAPI 在线玩家接口

在线玩家 API

### Player IP Logger 玩家 IP 记录

记录玩家IP地址
