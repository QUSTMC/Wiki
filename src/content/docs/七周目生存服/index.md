## 服务器常用插件使用指南

:::tip
本章节为简单使用指南，详细文档请移步[**服务器mod文档目录**](../mcdr命令与插件/)

下面这些指令都在游戏聊天栏里输入。开头的 `!!` 不能省略。

### 1. Gamemode：旁观 / 生存切换
[详细文档](./mcdr命令与插件/1_gamemode)

**它是干什么的？**  
想自由参观建筑、找地方、看别人在干什么，又不想影响生存？可以临时切成旁观模式。切回生存时，会回到你原来的位置。

**常用指令：**

- `!!spec`  
  切换自己的旁观 / 生存模式。

- `!!tp 玩家名`  
  传送到某个玩家身边。（仅旁观模式）

- `!!tp 主世界` / `!!tp 下界` / `!!tp 末地`  
  传送到对应维度。（仅旁观模式）

- `!!tp 维度 x y z`  
  传送到指定维度的坐标。（仅旁观模式）

- `!!back`  
  返回上一个地点。（仅旁观模式）

**小提醒：**  
旁观模式下不能挖方块、不能放方块、不能交互。想继续玩的时候，再输入一次 `!!spec` 切回生存即可。

---

### 2. Task：工程任务展示

[详细文档](./mcdr命令与插件/2_task)

**它是干什么的？**  
看看服务器里大家正在做什么大工程，还有什么没做完。适合一起建刷怪塔、挖空置域、修铁路这种长期项目。

**常用指令：**

- `!!task` 或 `!!task overview`  
  查看任务总览。

- `!!task list`  
  查看任务列表。

- `!!task add 任务名 说明`  
  添加一个任务。例如：  
  `!!task add 刷怪塔 收集材料`

- `!!task help`  
  查看帮助。

**小提醒：**  
不知道现在该干什么的时候，可以输入 `!!task` 看看大家缺什么、进度到哪了。

---

### 3. Where2go：坐标点共享与位置查询

[详细文档](./mcdr命令与插件/3_where2go)

**它是干什么的？**  
分享地点、保存坐标、查别人在哪里。找路、找建筑、找工地都很方便。

**保存坐标：**

- `!!wp addhere 名字`  
  把你现在站的位置保存为坐标点。例如：  
  `!!wp addhere 我家`

- `!!wp addpos 名字 x y z 维度`  
  手动添加坐标点。维度可以写：  
  `overworld`、`the_nether`、`the_end`  
  也可以简写：`o`、`n`、`e`

**查看和管理：**

- `!!wp list`  
  列出所有坐标点。

- `!!wp search 名字`  
  搜索坐标点。

- `!!wp info 编号`  
  查看某个坐标点的详情。

- `!!wp remove 名字`  
  删除坐标点。

**查位置：**

- `!!here`  
  广播你自己的位置。如果附近有已保存的坐标点，也会一起提示。

- `!!vris 玩家名`  
  查询某个玩家在哪里。

- 直接在聊天栏输入：  
  `XXX在哪`  
  可以快速查询坐标点 `XXX` 或玩家 `XXX` 的位置。

**小提醒：**  
如果你用的是 Xaero 地图，分享坐标后可以点 `[+]` 快速添加。

## 七周目fabric mod列表

### 1. 前置

- `fabric-api` Fabric API，绝对核心前置

- `servux` 为客户端mod提供数据同步

### 2. 性能优化与调试

- `[C^2M 引擎]` 多线程区块加载

- `[锂] lithium` 全方位底层优化

- `[铁氧体磁芯] ferritecore` 内存占用优化

- `[火花] spark` 性能分析排查工具

- `ScalableLux` 光照引擎优化

- `Very Many Players` 多人在线优化


### 3. 服务端管理、网络与版本兼容

- `LuckPerms` 权限管理

- `easywhitelist` 离线白名单管理

- `FabricProxy-Lite-2.12.0.jar` BungeeCord/Velocity 代理支持

- `ViaVersion` 高版本客户端进低版本服

- `ViaBackwards` 低版本客户端进高版本服

- `ViaFabric` 在 Fabric 端实现 Via 跨版本

### 4. 建筑、地图与录制工具

- `[创世神] worldedit` 强大的地图编辑与建筑工具

- `[共享原理图] syncmatica` 多人同步投影原理图

- `xaerominimap` xaero小地图，给客户端数据支持

- `xaeroworldmap` Xaero 世界地图，给客户端数据支持

- `Chunky` 区块预生成

- `Flashback` 录制与回放工具

### 5. Carpet系列

- `[地毯] carpet`

- `carpet-tis-addition`

- `gugle-carpet-addition`

### 6. 界面、社交与实用辅助

- `TAB` 自定义 Tab 菜单与信息显示

- `SkinsRestorer` 皮肤恢复与设置

- `LetMeClickAndSendForServer` 允许玩家在聊天栏特定组件点击发送文字(给where2go用的)
